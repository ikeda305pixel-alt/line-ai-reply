# LINE AI返信アシスタント (`line-ai-reply`)

**LINE（Android公式アプリ）専用**のAIスマート返信アシスタントです。
LINEの有料AI機能を、Google Geminiの**完全無料枠**を使って自作・自動化しました。

---

## 🌟 主な機能と特徴

1. **会話ログ（トーク履歴）を考慮した賢い返信案**
   - 直前の1通だけでなく、画面上の過去のやり取り（最大12通）を丸ごと読み取って文脈を理解。
   - 「自然な流れ」に沿った4つの返信案（共感＋質問、フレンドリー、ユーモア、お誘い・提案）を生成します。
2. **ワンタップで入力欄へセット（安全設計）**
   - 相手のメッセージをタップするか、画面端の「💬」バブルをタップすると返信案がパッと出現。
   - 案を選ぶと **LINEの入力欄に文字が入るだけ**（勝手に送信されないので誤送信やBANの心配なし！）。内容を確認して自分で送信ボタンを押せます。
3. **直に手書きしたい時も安心**
   - 「✍️ 直に入力」ボタンを押せば、アシスタントがサッと消えて普段通り手動でタイピングできます。
4. **完全無料・料金発生ゼロ**
   - Google AI Studio の無料キーに対応（未入力でも内蔵のスマートモックで即使えます）。
   - クレジットカード未登録で使えるため、1円も請求される心配はありません。

---

## 📱 インストール手順（Pixel 7単体でOK・PC不要）

1. Pixel 7のブラウザで **[Releases](../../releases)** を開きます。
2. 最新リリースの `app-debug.apk`（または `line-ai-reply.apk`）をタップしてダウンロードします。
3. ダウンロードしたファイルを開いてインストールします（「提供元不明のアプリ」を許可）。
4. Android 13/14の制限解除（初回のみ）：
   - Pixelの「設定」→「アプリ」→「LINE AI返信アシスタント」→ 右上「︙」→ **「制限付き設定を許可」**。
5. アプリを開き、**「ユーザー補助」** と **「重ねて表示」** をONにします。

---

## 💬 使い方

1. LINEで友だちとのトーク画面を開きます。
2. 画面の右端に出る **「💬」アイコン** をタップするか、**相手のメッセージをタップ**します。
3. 会話の流れに合わせた4つの返信案が出るので、好きなものを1つタップ。
4. LINEの入力欄に文章が入るので、送信ボタンを押すだけです！
