# LINE & Bumble AI返信アシスタント (`line-ai-reply`)

**LINE公式アプリ ＆ Bumble公式アプリ専用**のAIスマート返信アシスタントです。
Google Geminiの**完全無料枠**を使って、1本のアプリで両方のマッチング・メッセージ返信を自動化しました。

---

## 🌟 主な機能と特徴

### 1. LINE：会話の流れを最重視
- 直前の1通だけでなく、画面上の過去のやり取り（最大12通）を丸ごと読み取って文脈を理解。
- 食事、映画、休日、仕事など、会話の流れにぴったり沿った4つの返信案（共感＋質問、フレンドリー、ユーモア、お誘い・提案）を提示します。

### 2. Bumble：ラリー数に応じたLINE自動誘導 ＆ 英語自動判定
- **何ラリーかしたら自動でLINE交換を提案**:
  - **序盤（1〜2ラリー目）**: いきなりLINEを聞いて警戒されないよう、まずはプロフィールや話題に合わせた「共感＋質問」「フレンドリー」「ユーモア」で仲良くなる返信案を作成。
  - **中盤以降（3ラリー以上）**: 打ち解けた絶妙なタイミングで、第4案が**自動的に以下のLINE交換リンク付きメッセージ**へ進化します！
    > `予定立てやすいのでライン交換してください!`
    > `https://line.me/ti/p/TYxbDIk4sd`
  - ※序盤でもすぐLINEを聞きたい場合は「📲 LINE誘う」ボタンで即座に誘導案に切り替え可能！
- **英語の自動判定**:
  - 相手のプロフィールやメッセージから「英語で話すべき外国人か」をAIが自動判別。英語話者の場合は、自然な英語メッセージと英語のLINE誘導文（`It's much easier to plan and stay in touch on LINE!...`）を自動生成します！

### 3. ワンタップで入力欄へセット（安全設計）
- メッセージをタップするか、画面端の「💬」バブルをタップすると返信案がパッと出現。
- 案を選ぶと **入力欄に文字が入るだけ**（勝手に送信されないので誤送信やBANの心配なし！）。内容を確認して自分で送信ボタンを押せます。

### 4. 直に手書きしたい時も安心
- 「✍️ 直に入力」ボタンを押せば、アシスタントがサッと消えて普段通り手動でタイピングできます。

### 5. 完全無料・料金発生ゼロ
- Google AI Studio の無料キーに対応（未入力でも内蔵のスマートモックで即座に動作）。
- クレジットカード未登録で使えるため、1円も請求される心配はありません。

## 📱 インストール手順（Pixel 7単体でOK・PC不要）

1. Pixel 7のブラウザで **[Releases](../../releases)** を開きます。
2. 最新の `line-ai-reply.apk`（または `app-debug.apk`）をタップしてダウンロードします。
3. ダウンロードしたファイルを開いてインストールします（「提供元不明のアプリ」を許可）。
4. Android 13/14の制限解除（初回のみ）：
   - Pixelの「設定」→「アプリ」→「LINE AI返信アシスタント」→ 右上「︙」→ **「制限付き設定を許可」**。
5. アプリを開き、**「ユーザー補助」** と **「重ねて表示」** をONにします。

---

## 💬 使い方

* **LINEの場合**:
  トークを開いてメッセージまたは画面端の「💬」をタップ → 会話の流れに合わせた4案が出るので選んで送信。
* **Bumbleの場合**:
  チャットを開いてメッセージまたは画面端の「💬」をタップ → 相手が英語か日本語かを自動で見極め、LINE誘導リンク付きの返信案が出るので選んで送信。
