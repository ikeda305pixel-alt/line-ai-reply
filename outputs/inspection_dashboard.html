📍 画面外はみ出し（座標バグ） 修正済

症状：起動したのに画面のどこにも💬が見当たらない。

原因：x = screenWidth - 140という固定px計算のため、Pixelの高解像度画面（密度2.625〜3.5）ではView幅が242pxとなり、100px以上右画面外へ飛び出していた。

- p.x = screenWidth - 140
+ val w = bubbleWidth
+ val margin = 16 * density
+ p.x = screenWidth - w - margin
🛡️ Android 14/15 FGS例外 修正済

症状：起動ボタンを押した瞬間にサービスが即死していた。

原因：targetSdk 34ではstartForeground()時に型パラメータが必要。無指定だったためMissingForegroundServiceTypeExceptionが発生。

- startForeground(ID, notif)
+ ServiceCompat.startForeground(
+ this, ID, notif,
+ FOREGROUND_SERVICE_TYPE_SPECIAL_USE
+ )
🎨 MaterialTheme未適用例外 修正済

症状：レイアウトinflate時にIllegalArgumentExceptionでクラッシュ。

原因：Serviceはテーマを持たないContext。MaterialComponents用スタイルを直接inflateすると例外が飛ぶ。

+ ContextThemeWrapper(
+ context,
+ R.style.Theme_LineAiReply
+ ) を全オーバーレイに適用
