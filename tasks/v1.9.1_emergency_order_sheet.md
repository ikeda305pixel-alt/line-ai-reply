# 【注文票（Order Sheet）】v1.9.1 緊急改修＆ざっくばらん本音トーン完全復活

---

## 1. 🎯 完成イメージ（Goal & Deliverable）

1. **画面共有（MediaProjection）＆ユーザー補助（AccessibilityService）の完全撤廃（0行）**:
   - Android 15の画面共有黒画面ブロック（"セキュリティ上、画面共有ではアプリの内容は非表示となります"）を根本回避。
   - PayPay・銀行アプリの利用制限（RASP）を100%回避。
   - `FloatingBubbleService` の foregroundServiceType を `specialUse` とし、`PROPERTY_SPECIAL_USE_FGS_SUBTYPE` を正式定義。
   - バブル起動時は画面共有ダイアログを一切出さず、「他のアプリの上に重ねて表示」と「画像アクセス」のみで即座に起動。

2. **入力ルートA：OS標準スクリーンショット20秒自動検知（MediaStore + ContentObserver）**:
   - 電源＋音量下等のOS標準スクショを `ContentObserver` で自動検知。
   - 直近20秒以内の最新スクショを優先取得、`IS_PENDING == 0` を確認し、長辺1280pxに高品質リサイズ＆JPEG圧縮して Gemini Vision API へ高速送信。
   - 解析後に一時スクショを自動削除できるオプション設定。

3. **入力ルートB：クリップボード自動読み取り（Window Focus トリック）**:
   - スクショが無い場合、タップ時に `FLAG_NOT_FOCUSABLE` を一時解除して Window Focus を獲得し、Android 10+のバックグラウンド制限を回避してコピー文面を取得。直後にフラグを復元。

4. **APIキー未設定＆通信エラーの完全透明化**:
   - `AIzaSy` から始まる有効なキーが無い場合、ダミー返信を出さずポップアップ内に赤色で直接明示。
   - 通信エラー時もHTTPステータスコードとエラーメッセージを直接可視化。

5. **「ざっくばらん（自然体・本音・親近感）」トーンの完全復活**:
   - LINE＆Bumbleの両方で、気取らない等身大の本音やぶっちゃけトーク、親しい間柄でのクスッと笑える「ざっくばらん」な返信スタイルを案4（丁寧語でも親しみやすい本音共感）に正式採用。

---

## 2. 🚫 NG例（Anti-Patterns / やってはいけないこと）
- ❌ `MediaProjection` や `AccessibilityService` のコードが1行でも残っていること。
- ❌ 画面共有ダイアログが表示されること。
- ❌ APIキー未設定や通信エラー時に定型文ダミー返信が表示されること。
- ❌ 東京（渋谷・新宿等）を勝手に提案すること（必ず神奈川エリア）。
- ❌ ざっくばらんなフランクさ・親近感が消えて堅苦しい優等生文ばかりになること。
